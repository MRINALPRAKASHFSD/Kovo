# KOVO — API Documentation

## REST API

Base URL: `https://api.kovo.app/api/v1`

Interactive documentation is auto-generated by FastAPI:
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc**: `http://localhost:8000/redoc`
- **OpenAPI JSON**: `http://localhost:8000/openapi.json`

## API Versioning

All routes are versioned under `/api/v1/`. Breaking changes will introduce `/api/v2/`.

## Authentication

All protected endpoints require:
```
Authorization: Bearer <access_token>
```

## WebSocket API

WebSocket endpoint: `wss://api.kovo.app/ws`

See [websocket/](websocket/) for the full event protocol specification.

## Rate Limits

| Endpoint Group | Limit            |
|----------------|------------------|
| Auth endpoints | 10 req/min       |
| General API    | 60 req/min       |
| File upload    | 10 req/min       |
| WebSocket      | 5 connections/IP |
