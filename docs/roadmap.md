# KOVO — Product Roadmap

## Phase 1 — Core Messaging (v0.1.0)

**Goal**: A user can sign in, create a workspace, send a real-time message.

- [ ] Auth (email/password + Google OAuth)
- [ ] Workspace creation and membership
- [ ] Text channels
- [ ] Real-time messaging (WebSocket)
- [ ] Message edit and delete
- [ ] File attachments
- [ ] User presence

## Phase 2 — Rich Messaging (v0.2.0)

- [ ] Message threading
- [ ] Emoji reactions
- [ ] Full-text search
- [ ] Direct Messages
- [ ] Read receipts + typing indicators
- [ ] Phone OTP auth
- [ ] Push notifications (mobile)

## Phase 3 — Voice & Video (v0.3.0)

- [ ] Voice channels (WebRTC)
- [ ] 1:1 video calls
- [ ] Screen sharing
- [ ] Group calls

## Phase 4 — Platform (v0.4.0)

- [ ] Bot API
- [ ] Webhooks
- [ ] OAuth apps (KOVO as IdP)
- [ ] Server templates
- [ ] Rich presence

## ❌ Architecture is now frozen

From v0.1.0 onward, no folder reorganization, no tech stack debates.
Every sprint delivers working features on this foundation.
