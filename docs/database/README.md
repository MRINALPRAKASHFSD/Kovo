# KOVO — Database Documentation

## Engine

**PostgreSQL 16** — Production database.

## Schema Management

Migrations are managed by **Alembic**:

```bash
# Create a new migration
cd apps/backend
uv run alembic revision --autogenerate -m "add_message_threads"

# Apply migrations
uv run alembic upgrade head

# Rollback one step
uv run alembic downgrade -1
```

## Core Domain Entities (planned for Phase 1)

| Table            | Description                              |
|------------------|------------------------------------------|
| `users`          | User accounts and profiles               |
| `sessions`       | Auth sessions and refresh tokens         |
| `servers`        | Discord-like server/workspace            |
| `channels`       | Text, voice, and announcement channels   |
| `messages`       | Chat messages with threading             |
| `attachments`    | File/media attachments                   |
| `reactions`      | Message emoji reactions                  |
| `members`        | Server membership with roles             |
| `roles`          | Permission roles                         |
| `invites`        | Server invite links                      |
| `notifications`  | User notifications                       |
| `audit_logs`     | Server audit log entries                 |

## Conventions

- All primary keys: `UUID v4` (generated by PostgreSQL `uuid_generate_v4()`)
- All timestamps: `TIMESTAMPTZ` (timezone-aware)
- Soft deletes: `deleted_at TIMESTAMPTZ` (never hard-delete messages)
- Enum types: PostgreSQL native enums
