# KOVO — Feature Roadmap

## Phase 1 — Core Messaging (v0.1.0)

- [ ] User authentication (Email, Google OAuth, Phone OTP)
- [ ] Server / workspace creation and management
- [ ] Text channels
- [ ] Real-time messaging via WebSocket
- [ ] Message editing and deletion
- [ ] File and image attachments
- [ ] User presence (online, away, do not disturb, offline)
- [ ] Push notifications

## Phase 2 — Rich Communication (v0.2.0)

- [ ] Message threading (replies)
- [ ] Emoji reactions
- [ ] Message search (full-text)
- [ ] Direct Messages (DMs)
- [ ] Group DMs
- [ ] Read receipts
- [ ] Typing indicators
- [ ] Message pinning

## Phase 3 — Voice & Video (v0.3.0)

- [ ] Voice channels (WebRTC)
- [ ] Screen sharing
- [ ] Video calls (1:1 and group)
- [ ] Live streaming

## Phase 4 — Platform (v0.4.0)

- [ ] Bot framework
- [ ] Webhook integrations
- [ ] OAuth apps
- [ ] Rich presence (game/activity detection)
- [ ] Server templates
- [ ] Community features (forums, announcement channels)
